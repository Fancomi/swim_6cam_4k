# Core Windows runtime for the realtime stitch pipeline.
#
# Installed into the project .venv by install.bat, on Python 3.10 (the only ABI
# Autodesk ships an FBX Python SDK wheel for). The FBX SDK itself is NOT here:
# it has no PyPI distribution and install.bat pulls its installer from
# autodesk.com, then pip-installs the wheel that lands on disk.
#
# opencv-python-headless, not opencv-python: nothing in python/ opens a cv2
# window (previews are native Metal/D3D11/GL), so the GUI libs are dead weight.
#
# Pillow is a hard requirement of the frames chain, not an extra:
# python/labeling/merge_overhead.py imports it at module scope and
# python/labeling/frames.py imports that, so `run_frames.sh` and
# tests/python/test_{frames,merge_overhead}.py fail to import without it. It was
# missing here while the macOS prep check already asked for it
# (`python -c "import fbx, numpy, cv2, PIL"`), so a Windows box installed by
# install.bat could not run that chain at all.
numpy>=2.0,<3
opencv-python-headless>=4.10,<6
pillow>=10.0,<12
